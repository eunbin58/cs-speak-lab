# 🧠 CS Speak Lab

> **읽는 공부에서, 설명하는 공부로.**  
> CS 개념을 랜덤으로 뽑아 공부하고, 제한 시간 안에 직접 말로 설명한 뒤, 핵심 내용을 확인하며 기술면접을 준비하는 학습 앱입니다.

CS Speak Lab은 단순히 개념을 읽고 외우는 것보다 **스스로 설명할 수 있는지**에 집중합니다. 개념을 공부한 뒤 자료를 보지 않고 설명하고, 빠진 내용을 확인한 후 학습 상태를 기록하세요.

## ✨ 주요 기능

- **324개 CS 개념 · 11개 분야**: Java·Spring, 백엔드, 데이터베이스, 인프라·클라우드, 네트워크, 운영체제, 보안, 자료구조·알고리즘, 프론트엔드, 시스템 설계, 테스트·운영
- **중요도별 학습**: `필수`(기본 면접 개념), `중요`(응용 및 꼬리질문), `심화`(고급 설계·운영) 중 출제 범위를 선택
- **랜덤 키워드 출제**: 선택한 분야와 중요도에서 개념을 뽑고, 직접 제외한 개념은 출제하지 않음
- **3단계 학습 타이머**: 개념 공부 → 자료 없이 구두 설명 → 핵심 내용 비교 및 피드백
- **개념 카드 모음**: 한 줄 정리, 꼭 알아야 할 내용, 핵심 키워드, 관련 개념, 참고 자료 확인
- **학습 기록 및 복습 관리**: 자기평가 결과를 저장하고, 부족한 개념만 골라 복습

## 🚀 이렇게 사용하세요

### 1. 학습 분야와 중요도를 선택하세요

상단 **🎯 랜덤 학습** 메뉴에서 공부할 분야를 선택합니다. 여러 분야를 함께 선택해 복합적인 면접 질문에 대비할 수도 있습니다.

중요도는 다음 기준으로 분류했습니다.

| 중요도 | 의미 | 추천 상황 |
| --- | --- | --- |
| **필수** | 신입 백엔드 면접을 준비하며 우선 익혀야 할 기초 | 첫 번째 학습 회차 |
| **중요** | 기초를 바탕으로 답해야 하는 응용·실무 개념 | 기본 개념을 설명할 수 있게 된 이후 |
| **심화** | 깊이 있는 설계·동시성·운영 주제 | 심층 면접 또는 관심 직무별 보충 학습 |

> 중요도는 실제 기업의 공식 출제 빈도가 아니라, **신입 Java 백엔드 면접 준비를 위한 학습 우선순위**입니다.

### 2. 학습 모드를 선택하세요

| 학습 모드 | 공부 | 구두 설명 | 피드백 | 추천 상황 |
| --- | ---: | ---: | ---: | --- |
| ⚡ **빠른 복습** | 3분 | 2분 | 1분 | 이미 아는 개념 점검 |
| 📘 **일반 학습** | 7분 | 3분 | 2분 | 기본 학습 (**초기 선택 모드**) |
| 🔎 **심화 학습** | 15분 | 5분 | 3분 | 처음 접하거나 이해하기 어려운 주제 |

각 단계의 시간은 직접 수정할 수 있습니다. **랜덤 개념 뽑기 →**를 누르면 학습이 시작됩니다.

### 3. 개념을 공부하고 말로 설명하세요

1. **STEP 01 — 공부하기:** 제시된 키워드와 질문을 보고 정의, 동작 원리, 비슷한 기술과의 차이, 장단점, 적용 사례를 공부합니다.
2. **STEP 02 — 말로 설명하기:** 자료를 덮고 면접관에게 답하듯 소리 내어 설명합니다. 막힌 부분을 기억해 두세요.
3. **STEP 03 — 피드백 및 자기평가:** 참고 설명에서 **한 줄 정리 / 꼭 알아야 할 내용 / 핵심 키워드 / 함께 공부할 개념**을 확인합니다. 빠진 내용을 점검하고 피드백 시간이 끝나거나 **피드백 완료**를 누른 뒤 스스로 평가합니다.

공부·설명 타이머는 시간이 종료되면 다음 단계로 넘어가며, 필요하면 일시정지하거나 단계를 다시 시작할 수 있습니다. 설명 내용이 자동 녹음되거나 AI로 채점되는 기능은 현재 제공하지 않습니다.

### 4. 학습 상태를 기록하세요

설명을 마친 개념은 자기평가를 통해 다음 상태로 기록됩니다.

| 학습 상태 | 판단 기준 | 다음 행동 |
| --- | --- | --- |
| **다시 공부** | 정의나 기본 원리를 설명하기 어려움 | 개념을 처음부터 다시 학습 |
| **조금 부족함** | 기본 설명은 가능하지만 비교·사례·꼬리질문이 부족함 | 빠진 부분을 보완해 재도전 |
| **잘 설명함** | 정의, 원리, 차이와 실제 사례를 스스로 설명 가능 | 빠른 복습 또는 랜덤 출제 제외 |

학습 결과는 **최근 학습 기록**과 **개념 카드 모음**에서 다시 확인할 수 있습니다.

### 5. 개념 카드 모음에서 복습할 항목을 관리하세요

상단 **🗂 개념 카드 모음**을 열면 모든 개념을 카드 형태로 탐색할 수 있습니다.

- **검색**: 개념 이름이나 핵심 내용 검색
- **필터**: 학습 분야 / 중요도 / 학습 상태 / 랜덤 출제 포함 여부
- **내용 보기**: 한 줄 설명, 필수 내용, 키워드, 관련 개념과 참고 자료 확인
- **랜덤 제외 / 랜덤에 포함**: 이미 충분히 아는 개념은 제외하고, 다시 복습할 때 포함

**학습 상태와 출제 여부는 별개**입니다. `잘 설명함` 상태여도 랜덤 출제에 남길 수 있고, 필요하면 어떤 개념이든 직접 제외할 수 있습니다.

## 📚 추천 학습 루틴

**처음에는 `필수` + `일반 학습`으로 시작**하는 것을 추천합니다.

1. 하루에 **3개 개념**을 공부하고 직접 말로 설명합니다.
2. `다시 공부` 또는 `조금 부족함`으로 평가한 개념을 **개념 카드 모음**에서 필터링합니다.
3. 다음 학습에서 해당 개념을 **빠른 복습**으로 다시 설명합니다.
4. 충분히 설명할 수 있게 된 개념은 필요에 따라 랜덤 출제에서 제외합니다.
5. 기본 개념에 익숙해지면 `중요`, 이후 `심화`까지 확장합니다.

> **면접 답변 연습 팁:** ‘한 줄 정의 → 작동 원리 → 비슷한 기술과의 차이 → 선택 기준과 실제 사례’ 순으로 답해 보세요.

## 💾 학습 기록 안내

학습 상태, 최근 학습 기록, 랜덤 출제 제외 설정은 **현재 브라우저의 로컬 저장소**에 보관됩니다. 다른 브라우저·기기와 자동 동기화되지 않으며, 브라우저 사이트 데이터를 삭제하면 기록이 사라질 수 있습니다.
